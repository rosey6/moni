# Moni

**Moni** est une application de gestion de budget personnel : dépenses, revenus, budgets, abonnements, épargne et notifications.

## Fonctionnalités

- Tableau de bord et suivi des transactions
- Budgets mensuels et répartition par catégorie
- Abonnements et échéances
- Épargne libre et objectifs
- Notifications et préférences utilisateur
- Application web progressive (PWA)

## Technologies

HTML, CSS, JavaScript natif · PHP · MySQL · Nginx · PWA

## Structure

- `frontend/` — interface, assets et tests
- `backend/` — API PHP, schéma SQL, migrations et tests
- `deployment/` — exemples de configuration de déploiement
- `docs/` — documentation technique

## Installation rapide

```bash
cd frontend
pnpm install --frozen-lockfile
pnpm run test:unit
```

Voir le [guide de développement](docs/development.md) pour l'installation complète.
